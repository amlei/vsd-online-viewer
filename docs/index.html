VSD Online Viewer

自托管的 Microsoft Visio 图纸（.vsd）在线查看器。上传一份图纸，服务端用 libvisio 解析、再用自研 SVG 渲染器逐页渲染，浏览器里翻页、缩放、下载——不需要 Visio，不需要 Windows，也不经过任何第三方转换服务。

GitHub 仓库 快速开始

为什么不用通用转换器

通用 SVG 转换（librevenge 的 SVG 后端等）在工程图纸上会系统性丢内容：Visio 的 hairline（0 线宽）被写成 stroke-width:0，而 SVG 里 0 宽等于"不画"——整张图的细线、里程标尺、 符号会消失；文本的 fo:text-align、段落硬换行被丢弃，图签文字错位重叠。

本项目把渲染器换成自己的实现，逐条修掉这些问题（线宽按纸张单位、hairline 用 1px non-scaling stroke、文本自排版输出逐行 <tspan x y>、真实箭头路径、图案填充）。

关键特性

  • 逐页自包含 SVG：无外部字体/图片依赖，可直接下载、打印、嵌入其他系统
  • hairline 正确渲染：0 线宽按 1 设备像素绘制，不再整片丢失
  • 文本按 Visio 排版：段落硬换行、水平/垂直对齐、CJK 自动折行
  • 真实箭头与图案填充：使用 Visio 原始箭头路径，斜线填充输出为 SVG <pattern>
  • 零运行时依赖的服务端：Bun 直接运行，只用标准 API；纯前端，无构建步骤
  • 图纸库与去重：相同内容（sha256）自动复用

快速开始

git clone https://github.com/amlei/vsd-online-viewer.git
cd vsd-online-viewer
bun run build:renderer   # 构建渲染器（下载 libvisio 并打补丁）
bun start                # http://localhost:4310

环境要求：Bun ≥ 1.3；构建渲染器需要 librevenge / boost / icu4c / libxml2 与 C++17 编译器。

适用场景

  • 工程图纸（光缆/电缆径路图、站场图等）在内网集中查看
  • 把 Visio 图纸批量转成可嵌入、可打印的 SVG
  • 作为已有系统的渲染层：调用 CLI 或 HTTP API 取页面与文字坐标
